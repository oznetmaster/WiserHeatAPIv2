# NUnit 5 test migration

The maintained Wiser library suite uses NUnit 5.0.0, including awaited async exception assertions. CS4014 is a build error. The unreferenced NUnitTestProject folder was an unchanged Playwright getting-started tutorial visiting playwright.dev; it did not exercise Wiser. It has been retired instead of being counted as a migrated product suite. Its original source remains in Git history. No Wiser functionality or meaningful product test coverage was removed.
